HUMAN-COMPUTER INTERACTION / WEBSITE REDESIGN

DPWH Redesigned Website

Year: 2026 • Course Project • Polytechnic University of the Philippines

Project Overview

Redesigned the government website which is DPWH for Human-Computer Interaction. The objective was to apply core HCI principles to analyze and redesign key pages of the Department of Public Works and Highways (DPWH) website, optimizing the presentation of public infrastructure updates, department directories, and citizen service access.

Technologies Used
HTML CSS JavaScript TypeScript
Project Links dpwhRedesign.github.io ↗

My Contributions

  • 01 Assisted in redesigning website pages applying HCI principles.
  • 02 Helped document the design process and design decisions.
  • 03 Helped ensure that the written requirements were complete and clearly presented.
Project Showcase Side-by-Side Interface Comparison

Key Learning Experience

Working on the DPWH redesign taught me how to improve a website's user experience. I learned that a good website is not just about how it looks, but also how it shares information, guides users, and makes important public information easy to understand. Writing the project paper also helped me improve my technical writing and explain my design choices clearly.

Being part of a group project taught me the importance of dividing tasks, keeping documents organized, and communicating clearly with team members throughout the design process.

NO. 02 — SPECIAL CASE STUDY DISPATCH ACADEMIC RECORD • PESO EMPLOYMENT SYSTEM

WEB APPLICATION / DATABASE MANAGEMENT

PESO Employment Application System

Year: 2026 • Course Project • Polytechnic University of the Philippines

Project Overview

The PESO Employment Application System is a web-based application developed to digitize the manual employment application form used by the Public Employment Service Office (PESO). The system aims to make the application process more organized by allowing employment applicants to submit their information through a web interface and store their records in a database. It was developed using HTML, CSS, and JavaScript for the front end, with SQL and MySQL for database management.

Technologies Used
HTML CSS JavaScript SQL MySQL
Project Links peso_employment_tracker_system ↗

My Contributions

  • 01
    Assisted in the database normalization process to organize data, reduce redundancy, and maintain data consistency. Also helped create the Entity-Relationship Diagram (ERD) to represent the database structure and relationships between entities.
  • 02
    Contributed to preparing the project documentation, including the system's design and database structure.
  • 03
    Assisted in developing the web application, helping transform the existing manual form into a digital system using HTML, CSS, JavaScript, and database technologies.
Project Showcase Application Interface

Key Learning Experience

Through this project, I gained practical experience in database design, web application development, and technical documentation. I also learned how database structure and front-end development work together to support a more organized application process.

Translating paper-based municipal office workflows into normalized relational tables highlighted how crucial clean data architecture and form validation are for real-world user adoption.
